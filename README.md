# FinalProject-BuildWise

Responsive front-end prototype for Progress Report 2.

## Run locally

Open `index.html` directly, or run a local server from this folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Included screens

- Home
- Product listing
- Product details
- Shopping cart
- Checkout
- Order confirmation
- Smart Build Finder unique feature

Cart data is saved in the browser with `localStorage`. Checkout is a non-payment prototype.
